# 검색·최종 답변 분리 평가 v4 사전 고정

사용자는 R3 제안에 맞춰 검색과 답변을 나눈 평가를 요청했고, 실제 모델48문항1회·최대USD1을 승인했다. 한길 QA 범위만 변경한다.

- [질문·정답·규칙](../eval/split_holdout_v4.json), [메타데이터·SHA](../eval/split_holdout_v4.meta.json)를 후보 구현/새 출력 확인 전에 commit/push한다. 양성24·음성24, 한·영24쌍이다. 기존 v1/v2/v3·R3 공개셋과 정확한 문장 중복은 없지만 같은 도메인/유사 의도이며 사람 검토는 대기다.
- 검색: 공식 MemorySearch0.25/k3/상대0.5, 양성top3≥90%. 범위밖 빈 결과는 진단으로 별도 보고한다. 과거 검색오탐0 gate와 기존 실패 기록을 재라벨하지 않는다.
- 답변: 실제 Agent21378b5 + 후보024f307, gpt-4o-mini/v5·temperature0. 실제 가격·절차·출처의 지지를 문서와 대조한다. 근거 없는 주장·무관 출처·인용 오류0, 음성은cannot_answer+sources0을 요구한다. 거절만 하면 통과하지 못하도록 양성 유용성≥90%를 별도 gate로 둔다. regex는 진단이며 의미 사실성 증명이 아니다. R6 AI 검토와 사람 최종 검토를 구분한다.
- main/후보의 raw 질문 검색은 각1회, 실제 답변은 후보48문항1회만 평가한다. 실제 main 답변 성능 개선을 주장하지 않는다. 질문/gold/기준을 보고 바꾸거나 실패 문항을 재시도하지 않는다. 공개 후v4도 회귀용이 된다.
- 기존 Agent 프롬프트/행동은 유지하고 QA 모델 어댑터에 비용/횟수/토큰 상한만 둔다. API 재시도0·192회 상한·입력UTF8 32000바이트+토큰 여유1024·출력800토큰, 호출 전 최악 비용 예약으로USD1을 넘기기 전에 중단한다. 사용량 미확인은 예약액을 유지한다. 가격 출처는 [공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-4o-mini)다. 캐시 할인은 비용 계산에 사용하지 않는다.
- 실험은 메모리 검색과 stateless text AgentContext다. 배포/HTTP/실제 사진/운영DB/임베딩 호출은 하지 않는다. 원시 로그·키·계정비밀은 공개하지 않는다. 실제 사용량·반환 모델·예외·누락·인수 미완료를 보고한다.

이 사전 문서·데이터·메타와 인수인계를 먼저 고정한 뒤 QA 실행기를 검사하고 평가한다. 최종 사람 검토 전 제품 전체 승인으로 표시하지 않는다.
