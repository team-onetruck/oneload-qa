## Data/Backend: 무료 지점 사이 반납 경로가 유료 개찰구를 통과함

실제 `app.domain.routing.plan_route`에서 `ktx-hall → single-use-card-refund` 경로는 다음과 같다.

```text
ktx-hall → station-plaza → exit-1 → line1-gates-east
→ line1-concourse(paid) → line1-gates → single-use-card-refund
```

출발·도착은 free지만 “교통카드를 찍고 개찰구를 통과하세요” 뒤 바로 개찰구 밖으로 나오게 한다. free 노드만 남긴 그래프에서는 해당 두 지점 경로가 없다. 실제 무료 통로와 개찰구·카드 제약에 맞는 지도 연결/경로 정책을 확인해 달라는 요청이다. 모든 간선을 양방향으로 만들거나 실제 요금이 청구됐다고 단정하는 요청은 아니다. 완료 확인은 합의한 통행 제약으로 경로가 적절해지고 기존 목적지·휠체어 회귀도 유지되는 것이다.
